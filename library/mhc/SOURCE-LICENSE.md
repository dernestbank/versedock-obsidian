# Matthew Henry's Complete Commentary

Public Domain—Copy Freely. CrossWire's MHC 2.2 was prepared from CCEL text supplied by Logos Research. This is the complete commentary edition, including continuations. SwordDock queries the SWORD engine for each available WEB coordinate, groups identical adjacent entries within a chapter, and retains each section's exact original OSIS. Bounded inert rendering preserves headings, paragraphs, source quotations and supported emphasis. Qualified source references open an edition-labelled offline preview; missing or invalid addresses are not guessed. Separate book/chapter introduction keys are not exported. The source uses KJV versification; coordinates are not remapped.
