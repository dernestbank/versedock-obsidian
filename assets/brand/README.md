# SwordDock Bible identity

The open folio and notched ribbon identify SwordDock in a single color. Use the full name **SwordDock Bible** on first mention and **SwordDock** in running text. QuantGist is the publisher.

| Use | Artwork |
| --- | --- |
| Light background | [Horizontal wordmark](wordmark-light.svg) |
| Dark background | [Reverse wordmark](wordmark-dark.svg) |
| Obsidian ribbon | [Monochrome icon](ribbon.svg), inherits the theme’s text color |
| Profile tile, launcher or listing | [Scalable tile](app-icon.svg) · [512-pixel PNG](app-icon.png) |
| Standalone colored mark | [Folio and bookmark](mark.svg) |
| Release announcement | [1200 × 630 card](release-card.png) · [Vector master](release-card.svg) |

Use the wordmark at 160 px wide or larger. Below that, use the folio alone. At 16–24 px use the ribbon version, which keeps the gutter and bookmark distinct in one ink. Leave at least one quarter of the mark’s width as clear space. Preserve the artwork’s proportions.

The print palette pairs ink green `#173C36` with warm paper `#FAF5E9`. The bookmark uses terracotta `#A84932` on paper or `#E59271` on ink. Inside the plugin, controls and text inherit the Obsidian theme.

The wordmark is outlined for consistent rendering. Its typeface is Newsreader by Production Type, set at optical size 48 and weight 540. The original lettering remains editable as vector paths. The folio and ribbon are original vector drawings. [Newsreader font licence](Newsreader-OFL.txt)
